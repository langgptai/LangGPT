# 语言控制学：形式化理论体系

**Linguistic Cybernetics: A Formal Theoretical Framework**

---

## 〇、序言

语言控制学（Linguistic Cybernetics）是研究主体通过语言信号对大规模语言模型的行为空间施加约束、以实现目标输出的过程及其规律的学科。

它继承控制论（Cybernetics）的基本范式——信号、反馈、稳定性——但具有一个根本的结构性差异：在经典控制论中，控制信号与被控对象的运动处于不同的物理域（电信号控制机械位移）；而在语言控制学中，控制信号与被控输出**同构**——二者都是自然语言序列。控制的媒介即是被控的对象本身。这一同构性既赋予了语言控制以极大的灵活性，也构成了其理论复杂性的核心来源。

本文建立语言控制学的公理化基础，从元定义出发，经由基础概念层、控制力度量、策略类型学、反馈理论、策略自动合成理论与多目标控制理论，构建完整的理论大厦。

## 一、公理与元定义

### 公理 1（语言模型的概率本体）

语言模型 M 是一个条件概率分布。对任意输入序列 x，M 定义了所有可能输出序列 y 上的概率分布 P(y|x, M)。M 的一切外在行为均由此分布完全决定。

### 公理 2（控制的信号本体）

主体对 M 的一切影响均通过且仅通过输入序列 x 的构造来实现。主体无法直接修改 M 的内部参数，只能通过改变 x 来改变 P(y|x, M) 的形状。这一约束定义了语言控制学的基本边界条件。

### 公理 3（同构公理）

控制信号 σ 与被控输出 y 属于同一符号空间——自然语言序列的空间 L。即 σ ∈ L，y ∈ L。控制者用语言描述期望，模型用语言给出响应，二者在同一空间中交互。

### 公理 4（不可直接观测公理）

主体无法直接观测 M 的内部状态（权重、激活值、注意力分布）。主体只能通过观察输出 y 来推断 M 的行为特性。一切对 M 的了解都是通过输入-输出映射间接获得的。

### 公理 5（有限带宽公理）

任一单次交互中，控制信号 σ 的长度受上下文窗口 W 的硬性限制。即 len(σ) ≤ W。此外，M 对 σ 中不同位置信息的有效利用能力是非均匀的、随距离衰减的。

## 二、基础概念体系

### 定义 1（可能性空间 Ω）

给定模型 M，在接收任何特定输入之前，其理论上可生成的所有合法序列的集合，连同各序列上的概率测度，构成 M 的先验可能性空间：

Ω₀ = {(y, P(y|M)) | y ∈ L}

Ω₀ 是一个概率空间，其中 P(y|M) 为模型在无特定输入条件下对序列 y 的先验概率。在实践中，Ω₀ 的有效体积（概率质量集中的区域）由模型的训练数据分布决定。

### 定义 2（约束信号 σ）

主体向模型输入的一切信息的总和，称为约束信号，记作 σ。σ 包含但不限于：系统提示（system prompt）、用户消息（user message）、少样本示例（few-shot examples）、工具定义（tool schemas）、历史对话上下文、解码参数设定。

σ 的作用是将先验分布变换为后验分布：

P(y|M) → P(y|M, σ)

此变换即为"控制"的形式化定义。

### 定义 3（有效可能性空间 Ω(σ)）

施加约束信号 σ 后，概率质量集中到的子空间。取概率阈值 ε > 0，定义：

Ω(σ) = { y ∈ L | P(y|M, σ) > ε }

当 σ 越精确，Ω(σ) 越小，输出的确定性越高。当 σ 为空（无约束），Ω(σ) 退化为 Ω₀。

### 定义 4（目标空间 T）

主体期望获得的输出集合，记作 T ⊂ L。T 通常存在于主体的认知中，无法被完全形式化，但可以通过描述、示例、评估标准等手段近似刻画。

控制的终极目标是使 Ω(σ) 尽量逼近 T：

Ω(σ) → T

### 定义 5（控制力 C）

约束信号 σ 对可能性空间的压缩程度。采用信息论度量：

C(σ) = H(Y|M) − H(Y|M, σ)

其中 H 为随机变量 Y 的香农熵。C(σ) 表示 σ 消除的不确定性总量，即 σ 携带的关于输出的有效信息量。

等价地，C(σ) = I(σ; Y|M)，即约束信号与输出之间的互信息。

### 定义 6（控制误差 E）

目标空间 T 与有效可能性空间 Ω(σ) 之间的不匹配度。定义为两个集合之间的某种距离度量 d：

E(σ, T) = d(Ω(σ), T)

控制误差可以分解为两个正交分量：

溢出误差（Overflow Error）E⁺ = |Ω(σ) \ T|，有效空间中超出目标空间的部分，表征控制不够精确。

遗漏误差（Underflow Error）E⁻ = |T \ Ω(σ)|，目标空间中被有效空间排除的部分，表征控制过度约束。

总控制误差 E = E⁺ + E⁻。理想控制的条件是 E⁺ = E⁻ = 0，即 Ω(σ) = T。

### 定义 7（控制轮次 R）

单次 σ → y 的输入-输出交互构成一个控制轮次，记作 R = (σ, y)。

在多轮交互中，控制序列为 R₁, R₂, ..., Rₙ，其中 Rᵢ = (σᵢ, yᵢ)。后续轮次的约束信号可以依赖先前所有轮次的输出：σᵢ = f(y₁, ..., yᵢ₋₁, T)。

### 定义 8（控制通道 Channel）

约束信号 σ 可以通过不同的通道施加，每个通道具有不同的控制特性。主要通道包括：

语义通道：自然语言指令。灵活，但存在解释歧义。

结构通道：JSON Schema、XML 标签、固定模板。刚性约束，消除格式歧义。

示例通道：输入-输出示例对。高信息密度，隐式传递分布特征。

参数通道：temperature、top_p、top_k 等解码参数。直接作用于概率分布的形状。

工具通道：function calling、MCP 工具定义。约束行为空间而非纯语言空间。

上下文通道：历史对话、参考文档。提供信息基底，间接约束输出范围。

### 定义 9（控制阻抗 Z）

模型对特定约束信号的"抵抗"程度。形式化为：

Z(σ, M) = C_expected(σ) − C_actual(σ)

即约束信号理论上应实现的控制力与实际实现的控制力之差。Z > 0 表示模型未能完全遵循约束。

控制阻抗的来源包括：训练数据形成的强先验偏置、指令遵循能力的固有限制、约束与模型内在倾向的方向冲突。

当约束方向与模型先验分布的高密度方向一致时，称为顺先验控制，阻抗低。当约束方向与先验分布对抗时，称为逆先验控制，阻抗高。

### 定义 10（控制带宽 B）

单次约束信号能传递的有效控制信息量的上界。受三重限制：

物理带宽：上下文窗口长度 W。

有效带宽：模型注意力机制对长距离信息的利用效率，通常远小于物理带宽。

编码效率：自然语言作为信息载体的冗余度。同一控制意图可以用不同长度的文本表达，高冗余的表达浪费带宽。

## 三、信号分解理论

### 定理 1（信号正交分解）

任何有效的约束信号 σ 可以分解为四个功能正交的分量：

σ = σ_identity ⊕ σ_task ⊕ σ_constraint ⊕ σ_calibration

其中：

σ_identity（身份分量）：锚定模型的角色、知识域、行为模式。作用于 Ω 的全局拓扑结构——不缩小空间体积，而是旋转概率分布的朝向。

σ_task（任务分量）：定义任务类别。对 Ω 实施第一刀大幅切割，将无限可能收窄到特定任务类型的子空间。

σ_constraint（约束分量）：定义格式、长度、风格、禁忌、边界条件等具体限制。在任务子空间内实施精细雕刻。

σ_calibration（校准分量）：通过示例、参考输出、评分标准等方式传递"合格输出"的隐式分布特征。信息密度最高的分量。

### 定理 2（分量正交性原则）

四个分量应尽量在功能上正交，即每个分量独立地消除一个维度集合上的不确定性。当分量之间发生语义冲突时（如身份分量与约束分量矛盾），控制力因信号干涉而损失，有效可能性空间在冲突区间发生震荡，输出不确定性反而增加。

### 定义 11（信号效率 η）

单位长度约束信号实现的控制力：

η(σ) = C(σ) / len(σ)

不同信号类型的效率存在系统性差异。精确示例和结构模板的效率最高，具体否定指令次之，具体肯定指令居中，抽象描述效率低，冗余修饰效率为零或为负。

### 定理 3（信号效率第一原则）

在控制带宽有限的条件下，最优信号设计应优先使用高效率信号类型。在同等控制力需求下，一个精心选择的示例可以替代数倍长度的抽象描述。

### 定理 4（信号衰减定律）

在长上下文中，约束信号对输出概率分布的影响力随其与当前生成位置的距离增加而衰减。设信号 σ 位于位置 p，当前生成位置为 t，则 σ 的有效影响力 I(σ) 近似满足：

I(σ) ∝ g(t − p)

其中 g 为单调递减函数。具体衰减形式取决于模型架构，但衰减效应在所有 Transformer 架构中普遍存在。

### 定理 5（信号竞争定律）

当多个信号对同一输出维度施加不同方向的压力时，距离当前生成位置更近的信号在竞争中占据优势。即：位置效应可以覆盖语义强度。

推论（信号放置原则）：最关键的约束应在离生成位置最近的地方放置或重复强化。

## 四、控制力度量理论

### 定理 6（控制力上界）

对任意约束信号 σ，其控制力不超过约束信号与输出之间的互信息：

C(σ) ≤ I(σ; Y|M)

推论：模糊的约束信号不可能实现精确控制。控制力的上界由信号本身携带的信息量决定。

### 定理 7（控制力的边际递减）

控制力随约束信号长度增加的边际增量递减：

dC/d|σ| 随 |σ| 增加而递减

即：前几条约束消除大片不确定性，后续约束仅做边缘修正。

推论（最优约束密度的存在性）：存在最优约束密度点 |σ*|，超过该点后，增加约束的成本超过收益。超额约束不仅浪费带宽，还可能因约束间的微妙冲突产生信号干涉，反而降低控制力。

### 定理 8（控制-自由度权衡）

控制力 C 与输出多样性 D 严格负相关：

D(σ) = H(Y|M, σ) = H(Y|M) − C(σ)

不可能同时最大化输出的确定性与输出的多样性。对于事实性任务，应最大化 C（追求确定性）；对于创造性任务，应保留适度的 D（允许多样性）。

### 定理 9（阻抗匹配原则）

控制效率在约束信号方向与模型先验分布的梯度方向一致时最大。

η_effective(σ) = η(σ) · cos θ

其中 θ 为约束方向与先验梯度方向之间的夹角。当 θ = 0（顺先验），效率最大；当 θ = π（完全逆先验），效率最低甚至为负。

实践推论：在施加控制前，先了解模型的默认行为倾向，然后设计与之协调的最小偏移量约束信号。

## 五、策略类型学

### 定义 12（控制策略 Π）

控制策略是一个从状态到约束信号的映射函数：

Π: (观测历史, 目标空间, 状态) → σ

策略决定了在每个时刻应施加什么样的约束信号。

### 5.1 开环策略

定义：单次信号投射，不观测输出反馈。

Π_open: T → σ，σ → y，结束。

特性：设计哲学是一次性压入所有约束。适用于简单任务、批量处理、低成本场景。

### 定理 10（开环策略的复杂度天花板）

存在任务复杂度阈值 K，对于复杂度超过 K 的任务，开环策略的最小控制误差存在不可消除的正下界：

∀σ, 当 Complexity(T) > K 时，E(σ, T) ≥ E_min > 0

即：无论如何优化单次约束信号，对于足够复杂的任务，开环策略无法将控制误差降至任意低水平。

### 5.2 闭环策略

定义：多轮交互，每轮约束信号基于前序输出设计。

σ₁ → y₁ → f(y₁) → σ₂ → y₂ → f(y₂) → σ₃ → ...

核心组件是反馈函数 f。

### 定理 11（闭环策略的收敛性）

在控制阻抗有限且反馈函数信息量大于零的条件下，闭环策略的控制误差可以随轮次增加任意逼近零：

lim_{n→∞} E(σ₁...σₙ, T) → 0，当 Z < ∞ 且 I(f) > 0

### 定理 12（多轮控制优势）

在反馈信号质量足够高的条件下，n 轮闭环控制的累积控制力大于等于任意单轮控制的控制力：

C(σ₁...σₙ) ≥ max_i C(σᵢ)

### 定理 13（上下文膨胀代价）

闭环策略中，每轮的历史记录占据控制带宽，导致后续轮次的可用控制带宽递减：

B_available(n) = W − Σᵢ₌₁ⁿ⁻¹ len(σᵢ, yᵢ)

当 B_available 降至临界值以下时，新约束信号的有效控制力急剧下降。

### 5.3 级联策略

定义：将大任务分解为多个子任务，子任务间通过结构化接口传递精炼后的中间产物，不共享完整上下文。

σ_A → y_A → extract(y_A) → σ_B(含提取结果) → y_B → ...

解决上下文膨胀问题，代价是接口处可能丢失信息。

### 定义 13（接口信息瓶颈）

级联策略中，子任务间的接口函数 extract 定义了一个信息瓶颈：

I_through = I(y_A; σ_B) ≤ I(y_A; extract(y_A))

接口设计不良导致 I_through 过小，关键信息在传递中丢失。

### 5.4 分治策略

定义：将任务分解为可并行的独立子问题，分别控制后合并。

σ₁ → y₁、σ₂ → y₂、σ₃ → y₃ → merge(y₁, y₂, y₃) → y_final

适用条件：子问题之间近似独立。

### 5.5 对抗策略

定义：用一个模型调用验证另一个模型调用的输出，形成生成-验证对偶结构。

σ_gen → y_gen → σ_verify(含 y_gen 与验证标准) → y_verdict → 条件分支

本质是利用模型自身的判断能力构建误差检测机制。

## 六、反馈函数理论

### 定义 14（反馈函数 f）

闭环策略中，反馈函数 f 将当前输出与目标空间的偏差转化为下一轮约束信号：

f: (yᵢ, T, history) → σᵢ₊₁

### 定理 14（反馈函数的三阶段分解）

任何反馈函数 f 可以分解为三个串行阶段：

评估阶段 E：E(yᵢ, T) → δ，将输出与目标的偏差投影为多维偏差向量。δ = (δ₁, δ₂, ..., δₖ)，每个分量对应一个质量维度上的偏离。

归因阶段 A：A(δ, yᵢ, σᵢ) → cause，将偏差归因于特定原因类别。原因类别包括信号缺失、信号模糊、信号冲突、阻抗过高、能力边界。

生成阶段 G：G(δ, cause) → σᵢ₊₁，基于偏差和归因构造校正信号。

反馈质量的上界由评估阶段决定，反馈效率由归因阶段决定，反馈的可执行性由生成阶段决定。

### 定义 15（反馈模式分类）

反馈信号按信息密度递增分为五种模式：

模式一，情绪反馈：仅传递满意/不满意的一维标量信号。如"不好""重来"。信息量约 1 bit。

模式二，维度反馈：指出偏差发生在哪个维度。如"逻辑对但语气不对"。信息量约 log₂(k) bits，k 为维度数。

模式三，梯度反馈：指出偏差维度并给出校正方向与近似幅度。如"语气太学术，要像 TED 演讲那样"。通过锚点传递方向和幅度信息。

模式四，示例反馈：直接提供目标空间中的样本点。如手写一段范文。同时精确传递所有维度上的目标位置。信息量最高，成本也最高。

模式五，对比反馈：同时给出当前输出（负例）与期望方向（正例），并标注差异维度。在可能性空间中同时标定两个点并指出向量方向。

### 定理 15（反馈收敛速度定理）

控制序列收敛到目标所需的期望轮次与反馈模式之间满足严格排序：

n(情绪) >> n(维度) > n(梯度) > n(对比) ≥ n(示例)

形式化地，收敛轮次正比于有效可能性空间的维度数，反比于每轮反馈信号携带的关于目标的互信息：

n_converge ∝ dim(Ω(σ)) / I(f(yᵢ); T)

### 定理 16（反馈信息瓶颈定理）

无论模型能力多强，若反馈函数每轮仅传递 k bits 信息，则每轮最多消除 k bits 的不确定性。对于需要消除 N bits 不确定性的任务，收敛所需最少轮次为：

n_min = ⌈N / k⌉

推论：提升收敛速度的根本途径是提高反馈信号的信息密度，而非增加轮次。

### 定义 16（反馈病理 Feedback Pathologies）

闭环控制中可能出现四种系统性反馈失效模式：

振荡（Oscillation）：反馈过度校正，导致输出在目标两侧反复跳跃。根因是反馈的幅度信号不准确。解法：引入程度锚点。

漂移（Drift）：每轮修正一个维度，但其他维度在修正过程中悄然偏移。经过多轮后，最初达标的维度已失控。根因是缺少维度保持信号。解法：显式声明已达标维度需保持不变。

过拟合（Overfitting to Feedback）：模型将局部校正意见泛化为全局原则。如"第三段加个例子"导致每段都加了例子。根因是校正信号缺少作用域标记。解法：明确约束的适用范围。

信号退化（Signal Degradation）：在长对话中，早期高质量约束被后期大量文本稀释，模型对初始指令的遵循度下降。根因是上下文膨胀导致信号竞争失利。解法：在关键轮次重复核心约束，或用级联策略截断上下文。

### 定理 17（最优反馈六原则）

最优反馈函数应同时满足以下六项原则：

多维性原则：每次反馈应同时覆盖多个偏差维度，而非逐维度串行修正。

对比性原则：优先使用"A 而非 B"的对比结构，消除解释歧义。

锚定性原则：提供程度锚点和参考实例，将抽象方向具体化。

保持性原则：显式声明哪些维度已达标、需在后续修正中保持不变。

作用域性原则：明确标注校正的适用范围——全局还是局部，哪一段哪一句。

归因先行原则：在给出校正指令前，先正确归因偏差来源，避免在错误方向上精确校正。

## 七、策略自动合成理论

### 定义 17（元策略函数 π）

元策略函数是一个从任务描述到约束信号序列的映射：

π: (T, M) → σ* = (σ₁, σ₂, ..., σₙ)

其中 σ* 为使控制误差最小化的最优约束序列。π 的构造即为"策略自动合成"问题。

### 定义 18（自动合成的层次模型）

策略自动合成按自动化程度分为五个层次：

L0 人工手写：人类直接撰写约束信号。完全依赖人类经验。

L1 模板填充：人类设计参数化模板，系统根据任务自动填充变量。

L2 信号搜索：系统在候选信号空间 Σ 中搜索最优 σ，需要评估函数 Q(y, T) 评判输出质量。形式化为 σ* = argmax_{σ ∈ Σ} E[Q(M(σ), T)]。

L3 信号编译：从高级任务描述自动编译出低级约束序列，包括子任务分解、执行顺序安排、接口设计。

L4 策略学习：系统通过与模型的反复交互学习泛化的策略函数 π，使其能应用于未见过的任务类型。

### 定理 18（评估函数的递归困境）

自动合成系统的优化上界受限于其评估函数 Q 的质量。当 Q 本身依赖语言模型实现时，Q 的优化自身也是一个控制问题，形成无限递归：

优化 σ 需要好的 Q → 优化 Q 需要好的评估 prompt → 评估 prompt 需要优化 → ...

递归的出口仅有两种：人类判断（human-in-the-loop 提供终极评估锚点）或客观度量（代码执行结果、检索准确率等不依赖语言模型的指标）。

### 定理 19（搜索空间的非凸性）

约束信号空间 Σ 是离散的、高维的、非凸的。具有以下拓扑特性：同义改写构成平坦区域（不同措辞、相同效果），单词替换可能导致输出巨变（语义悬崖），多个局部最优解可能分散在空间中不连通的区域。传统连续优化方法不直接适用。

### 定义 19（校准参数优化原理）

在信号四分量中，σ_calibration（示例选择）的优化比 σ_task 和 σ_constraint（指令措辞）的优化更 tractable，因为：示例的质量评估比指令措辞的质量评估更客观；示例选择是组合优化问题，优于在连续语义空间中的搜索；好的示例对指令措辞的变化具有鲁棒性。

推论：自动合成系统应优先优化示例选择，同时用程序结构固定任务和约束分量，以减少需要搜索的自由度总量。

### 定理 20（自动合成的可行性边界）

自动合成在以下条件下可行且高效：存在客观评估标准、任务结构可分解、大量同类任务需复用策略、人类判断成本远高于计算成本。

自动合成在以下条件下不可行或低效：评估高度主观、任务独一无二不值得优化、目标空间本身模糊（主体自身无法清晰定义 T）、需要实时人类价值判断。

## 八、多目标控制理论

### 定义 20（多维目标空间）

当目标空间 T 由多个质量维度构成时，T 可以表示为各维度目标的笛卡尔积：

T = T₁ × T₂ × ... × Tₖ

其中 Tᵢ 为第 i 个维度上的目标区间。典型维度包括准确性、创造性、简洁性、可读性、全面性、风格一致性等。

### 定义 21（维度冲突关系）

两个目标维度 Tᵢ 和 Tⱼ 之间的关系可以分为三类：

协同关系：提升 Tᵢ 的约束同时提升 Tⱼ。如逻辑性与准确性。

独立关系：提升 Tᵢ 的约束不影响 Tⱼ。

冲突关系：提升 Tᵢ 的约束降低 Tⱼ。如全面性与简洁性。冲突关系进一步分为强冲突（几乎不可调和）与弱冲突（可通过巧妙设计缓解）。

### 定义 22（帕累托前沿）

对于存在冲突的维度集合，帕累托前沿 PF 是所有帕累托最优输出的集合——在不恶化任何一个维度的前提下，无法再改善任何其他维度的输出：

PF = { y | ¬∃y' : ∀i, Qᵢ(y') ≥ Qᵢ(y) ∧ ∃j, Qⱼ(y') > Qⱼ(y) }

其中 Qᵢ 为第 i 个维度的质量函数。

### 定理 21（帕累托不可逾越定理）

对于给定模型 M，在真正冲突的维度上，不存在约束信号 σ 使得输出在所有冲突维度上同时超越帕累托前沿。

任何声称在所有维度上同时最优的策略，必然满足以下条件之一：维度之间并不真正冲突；或在某个未被显式度量的维度上做了妥协。

### 定义 23（帕累托前沿的几何形态）

对于两个冲突维度 A 和 B，帕累托前沿在 (Qₐ, Q_b) 平面上形成一条曲线。该曲线的凸凹性决定了最优策略的形态：

凸前沿：中间折中方案的效用接近两个极端。简单的加权混合即可获得令人满意的折中。

凹前沿：中间折中方案的效用严格低于两个极端的加权平均。折中意味着两头不讨好。

### 定理 22（凹前沿分离定理）

当帕累托前沿为凹时，分离策略（生成多个偏向不同极端的变体供主体选择）的期望效用严格高于折中策略（在一次输出中试图平衡所有维度）：

E[U(分离)] > E[U(折中)]，当 PF 为凹时

### 定义 24（优先级表达的三种形式）

主体在多目标控制中表达维度间优先级的方式：

显式权重：为每个维度赋予数值权重 wᵢ，最大化加权总分 Σ wᵢQᵢ。

字典序：给出维度的严格优先级排序。对最高优先级维度设定阈值，在满足阈值的输出集合内优化下一优先级维度，逐层过滤。

否定式：声明哪些维度绝对不可牺牲（硬约束），剩余维度为可交易的软目标。

### 定理 23（字典序的最优性）

在维度间存在强冲突的条件下，字典序优先级表达的控制效率高于显式权重，因为：字典序将多目标问题分解为一系列单目标问题，每层控制的搜索空间严格缩小；而显式权重要求模型在连续权衡空间中寻找平衡点，搜索难度更大。

### 定义 25（帕累托滑动 Pareto Sliding）

多目标闭环控制中的一种病理模式：每轮修正一个维度时，其他维度沿帕累托前沿滑落。多轮修正后，输出在帕累托前沿上来回移动，不收敛于主体期望的位置。

### 定理 24（多目标控制的四种策略框架）

分层锁定法：按字典序逐层锁定。先优化最高优先级维度，达标后显式锁定（声明不变），在锁定约束下优化次优先级维度。将多目标问题分解为串行单目标问题序列。

帕累托采样法：让模型一次生成多个变体，每个偏向不同权重组合，主体从帕累托前沿上直接选择。将搜索从串行（多轮修改）变为并行（一轮多版本）。

约束-优化分离法：将部分维度转化为硬约束（设定固定阈值），仅在剩余维度上优化。减少自由度，消除帕累托滑动。

分阶段解耦法：在级联策略中，不同阶段优化不同维度。如先生成完整准确内容，再编辑压缩，再润色风格。每阶段为单目标控制问题，前阶段的输出维度在后阶段中转化为保持性约束。

### 定理 25（维度独立性简化定理）

若目标维度集合内所有维度之间均为协同或独立关系，则多目标问题退化为多个独立的单目标问题，可以用一个信号同时优化所有维度，无需帕累托权衡。

## 九、控制序列的优化理论

### 定义 26（状态摘要函数 s）

在多轮控制中，状态摘要函数将完整交互历史压缩为有限维度的状态向量：

s: (σ₁, y₁, σ₂, y₂, ..., σₙ, yₙ) → state ∈ S

好的状态摘要函数保留与后续控制决策相关的信息，丢弃冗余细节。

### 定理 26（马尔可夫控制原理）

若状态摘要函数 s 具备充分统计量性质（即 state 包含了预测最优后续信号所需的全部信息），则最优控制策略可以简化为马尔可夫策略：

σₙ₊₁ = π(state_n, T)

即下一步约束信号仅依赖当前状态摘要和目标空间，不需要访问完整历史。

实践推论：上下文管理的本质是设计好的状态摘要函数——何时总结历史、何时开新会话、何种信息必须保留。

### 定义 27（探索-利用权衡）

在多轮控制的第 i 轮，主体面临选择：

探索（Exploration）：发出开放性约束信号，保持 Ω(σᵢ) 较大，以获取模型能力边界和先验倾向的信息。本质是系统辨识。

利用（Exploitation）：发出精确约束信号，缩小 Ω(σᵢ)，直接获取目标输出。本质是执行控制。

### 定理 27（先探索后利用原则）

对未知特性的模型施加控制时，最优策略的前期阶段应偏向探索、后期阶段偏向利用。对不了解的系统直接施加精确控制，可能高效地逼近一个错误目标。

### 定义 28（鲁棒控制力）

约束信号在模型变体集合上的最差情况控制力：

C_robust(σ) = min_{M ∈ M} C(σ, M)

其中 M 为可能遇到的模型变体集合（不同版本、不同厂商、不同参数设置）。

### 定理 28（鲁棒性-最优性张力）

对特定模型极限优化的策略 σ*_M 通常不是鲁棒最优策略 σ*_robust。在需要跨模型工作或抵抗模型更新的场景中，应追求鲁棒最优而非绝对最优。

鲁棒策略的一般特征是：依赖语义清晰度胜过依赖模型特定行为，依赖显式结构约束胜过隐式模式暗示。

## 十、交互式目标发现

### 定义 29（目标漂移 Target Drift）

在多轮控制过程中，主体的目标空间 T 并非固定不变。模型的输出 yᵢ 可能改变主体对目标的认知，导致 T 在交互过程中发生演化：

T₀ → T₁(受 y₁ 影响) → T₂(受 y₂ 影响) → ...

这一现象在经典控制论中没有对应物——传统被控对象的输出不会改变控制者的目标函数。

### 定义 30（交互式目标发现）

当主体在交互开始时无法清晰定义 T，而是通过与模型的多轮交互逐步发现、澄清、精化自己的目标时，这一过程称为交互式目标发现（Interactive Target Discovery）。

在这种模式下，控制的目的不仅是让模型逼近目标，更是借助模型的输出帮助主体认知自己的目标。前几轮交互的价值不在于获取合格输出，而在于通过模型的"提案"帮助主体排除不想要的方向、确认想要的方向。

### 定理 29（双重收敛）

在交互式目标发现模式下，成功的控制序列需要达成双重收敛：

Ω(σₙ) → Tₙ（有效空间逼近目标空间）

Tₙ → T*（目标空间收敛到稳定值）

单纯的第一类收敛不够——如果目标本身尚未稳定，对着一个漂移的目标做精确控制是浪费。最优策略应当感知目标是否已经稳定，在目标未稳定时偏向探索（帮助主体澄清目标），在目标稳定后转向利用（精确逼近目标）。

## 十一、公理体系的完备性与开放问题

### 本体系的覆盖范围

以上公理体系从五条公理出发，经由 30 个定义和 29 条定理，覆盖了语言控制学的六大分支：基础概念论（可能性空间、控制力、控制误差）、信号设计论（信号分解、信号效率、信号衰减与竞争）、策略类型学（开环、闭环、级联、分治、对抗）、反馈函数理论（反馈分解、反馈模式、收敛速度、反馈病理）、策略自动合成理论（层次模型、评估困境、搜索空间性质）、多目标控制理论（帕累托前沿、维度冲突、策略框架）。

### 开放问题

以下方向尚未被本体系充分覆盖，标记为未来研究方向：

可观测性理论：如何从模型输出 y 中推断模型内部状态？这涉及可解释性（interpretability）的控制论视角，需要定义状态可观测性的条件与限度。

系统辨识理论：如何通过系统化实验探测模型的先验可能性空间 Ω₀ 和控制阻抗 Z 的分布？这是红队测试（red teaming）和能力激发（capability elicitation）的理论基础。

多主体控制：当多个主体同时或序贯地对同一模型施加约束信号时（如 system prompt 的设计者与 user message 的发送者是不同主体），其控制信号之间的博弈结构是什么？

控制的伦理维度：约束信号不仅可以引导模型输出有益内容，也可以引导其产生有害输出。语言控制学的理论工具同时可以服务于对齐（alignment）与误用（misuse），这一对偶性需要专门的伦理分析框架。

控制理论的实证验证：本文建立的定理多数基于理论推导和实践直觉，尚需设计可量化的实验方案进行系统验证。特别是控制力的度量、反馈收敛速度的实测、帕累托前沿的经验形状，均需要实验数据的支撑。
